# ReadBook 本地听书与句子高亮设计

日期：2026-09-01

## 背景与目标

ReadBook 需要增加完全本地的中文听书能力。用户点击播放后，应用从当前阅读位置继续朗读；用户也可以选中文字，并通过选区附近的“从此处开始听”浮层从选区首字符起播。朗读过程中，当前句子在正文中高亮，两种阅读模式继续共享现有 UTF-16 offset 阅读位置。

首版目标：

- 使用本地神经语音，断网后可继续听书，小说正文不离开设备。
- 使用 `Qwen3-TTS 1.7B CustomVoice 8-bit`、`Serena` 声线和固定的中文小说旁白指令。
- 使用 `Qwen3 ForcedAligner 0.6B 4-bit` 获取句子时间范围，兼顾整段朗读的连贯性和高亮准确性。
- 普通阅读不下载、不加载语音模型。只有用户首次使用听书时才扫描本地模型并下载缺失文件。
- 支持 `0.5x` 至 `1.5x` 倍速，按 `0.1x` 调整，实时生效并保持音调。
- 将待播放句子维持在 10 至 30 条：低水位 10 条、目标 20 条、硬上限 30 条。
- 保持窗口现有单一顶部区域、约 30 × 30 pt 点击热区和低打扰交互。

首版不做：

- 云端 TTS、账号、云同步或上传小说文本。
- 自动识别角色并切换多人声线。
- 用户训练、微调或克隆声音。
- 跨设备同步听书位置。
- 在发布包内附带约 3.8 GB 模型。

## 已确定的产品决策

### 模型与声线

- TTS：`mlx-community/Qwen3-TTS-12Hz-1.7B-CustomVoice-8bit`，约 2.9 GB。
- 时间对齐：`mlx-community/Qwen3-ForcedAligner-0.6B-4bit`，约 0.9 GB。
- TTS revision：`41d3337e8b7f2843a75841595fc14e4b9a7a4b96`。
- 时间对齐 revision：`2f652af86ae0c73fe189b9429225c908ce4bf020`。
- 默认声线：`Serena`。
- 固定指令：使用清澈、干净、少气声、不沙哑的年轻女声，像专业有声书主播一样朗读；对白情绪自然，旁白克制沉浸，吐字清晰，停顿合理。
- 首版不再保留 0.6B 或其他 TTS 模型选项。

### 起播位置

- 工具栏播放从当前权威 UTF-16 阅读位置所在的完整句子开始。
- 选区浮层起播严格使用选区第一个 UTF-16 字符，不退回句首。
- 若选区起点位于句中，首条朗读文本为“选区起点到当前句末”；随后继续正常分句。
- “从此处开始听”不是只朗读选区，而是从该位置持续向后朗读整本书。
- 新起播请求会取消现有生成、清空旧队列并停止旧音频，防止串书或串位置。

### 阅读位置

- `BookPosition.utf16Offset` 继续是分页、连续阅读和听书共享的唯一权威位置。
- 当前朗读句切换时，将该句全局 UTF-16 起点写入 `ReaderSession`。
- 同一运行会话内暂停和恢复保留当前音频帧位置，从句中剩余部分继续。
- App 退出后不保存句中音频帧；下次从已保存句子的起点重新开始，避免引入第二套持久进度。

## 技术路线

### 原生依赖

使用 `mlx-audio-swift`，只向 ReadBook App target 引入以下产品：

- `MLXAudioCore`
- `MLXAudioTTS`
- `MLXAudioSTT`

依赖必须锁定到经过验证的 tag 或 commit，不跟随 `main` 漂移。兼容性试验以已检查的 `3506fb93cc3b9e4a642079d5384eaca0373962e6` 为候选；真实模型测试通过后才能将它写入 `Package.swift`。当前上游源码已提供：

- Qwen3-TTS Base、CustomVoice 和 VoiceDesign 支持。
- 通过 `voice` 参数传入“`Serena, <指令>`”形式的 CustomVoice 条件。
- TTS 流式生成。
- Qwen3 ForcedAligner 4-bit 模型加载和词级开始/结束时间。

不在 App 内捆绑 Python、Conda、虚拟环境或本地 HTTP 服务。

### 模块边界

#### `ReadBookCore/Speech/SentenceSegmenter`

负责把全书文本和起始 UTF-16 offset 转为稳定的句子序列。输出每条句子的原文和全局 UTF-16 范围。

分句规则覆盖：

- 中文句号、问号、感叹号、省略号和换行。
- 成对中文引号后的标点。
- 连续标点，如 `？！`、`……`。
- 选区起点位于句中时的首条截断句。
- emoji、代理对和组合字符，不能切断 UTF-16 组合字符序列。

该组件不依赖 MLX，可在 Core 中做快速单元测试。

#### `ReadBook/Speech/SpeechModelManager`

负责模型发现、校验、下载、删除和状态发布，不接触小说文本。

状态最小化为：

- `notInstalled(missingBytes)`
- `discovering`
- `downloading(progress, downloadedBytes, totalBytes)`
- `ready`
- `failed(message)`

模型目录以 `Application Support/ReadBook/Models` 为权威位置。首次使用听书时按以下顺序查找：

1. ReadBook 自有模型目录。
2. `HF_HOME` 指向的 Hugging Face 缓存。
3. `~/.cache/huggingface/hub`。
4. `~/Library/Caches/huggingface/hub`。

只接受模型 ID、revision、配置文件和权重分片都匹配清单的目录。存在 `.incomplete` 文件、缺少分片或 revision 不匹配都视为缺失，不能直接加载。

当前开发机试听模型位于 ReadBook 创建的临时目录。实现阶段将这份 1.7B 模型迁入 ReadBook 自有模型目录，不重复下载。产品代码不硬编码该临时路径，也不移动其他应用拥有的 Hugging Face 缓存。

下载要求：

- 仅在用户点击“下载并开始听书”后进行。
- 弹窗展示实际缺失容量；本机已有 TTS 时只显示约 0.9 GB。
- 下载到 `.partial` 目录，支持取消和断点续传。
- 开始前检查可用空间，至少保留缺失文件体积加 15% 的余量。
- 完成后校验清单，再使用原子 rename 进入正式目录。
- 下载失败不改变阅读位置，不影响普通阅读。
- 设置页提供“删除听书模型”，删除前停止播放并释放模型。

#### `ReadBook/Speech/SpeechSynthesisEngine`

封装 Qwen3-TTS，输入一段连续文本和全局 UTF-16 范围，输出 24 kHz 单声道 PCM 音频。它固定使用 Serena 和既定指令，不向首版 UI 暴露模型采样参数。

为保持韵律，输入块优先使用完整自然段；过长段落按 2 至 5 句的短语义块拆分。首句为降低启动等待可单独生成，后续块再恢复连续上下文。

#### `ReadBook/Speech/SpeechAlignmentEngine`

封装 Qwen3 ForcedAligner。输入合成音频和对应原文，输出词级时间范围；随后根据 `SentenceSegmenter` 的句子边界合并为句级时间范围。

每个句级条目包含：

- 全局 UTF-16 范围。
- 在当前音频块中的开始和结束采样帧。
- 对应的展示文本。

若单个块对齐失败，只将该块回退为逐句生成，不使用按字数估算的漂移高亮，也不影响已经排队的块。

#### `ReadBook/Speech/SpeechQueue`

使用 actor 持有待播放句子和生成任务，所有请求带 generation ID。任何跳转、换书或重新起播都会递增 generation ID；旧任务即使晚返回也会被丢弃。

队列策略：

- 低水位：10 条可消费句子。
- 目标水位：20 条。
- 硬上限：30 条。
- 队列降至 10 条时开始补充，补到至少 20 条。
- 如果一个自然段会使队列略高于 20 条但不超过 30 条，可以整体加入。
- 达到 30 条后立即停止预生成。
- 暂停时保留现有队列，但不继续越过目标水位生成。
- 跳转、换书、删除模型或结束听书时清空队列并取消生成。

PCM 只保存在有界内存队列中，不预先为整本书生成文件。这样既避免磁盘缓存膨胀，也保证生成内容始终接近当前消费位置。

#### `ReadBook/Speech/SpeechPlaybackController`

使用 `AVAudioEngine`、`AVAudioPlayerNode` 和 `AVAudioUnitTimePitch` 播放 PCM：

- 倍速范围 `0.5x...1.5x`，步长 `0.1x`。
- 调速保持音高，改变后立即作用于正在播放的音频。
- 高亮以播放器消费的源采样帧为时钟，不使用墙上时间，因此运行中切换倍速不会让高亮漂移。
- 音频块结束时无缝调度下一块。
- 缓冲耗尽时进入“准备中”，保留当前位置；补充后自动续播。

播放状态为 `idle / preparing / playing / paused / buffering / failed`。控制器只发布状态、当前句 UTF-16 范围和队列数量，不直接操作 SwiftUI 或 NSTextView。

#### `ReadBook/Speech/AudiobookController`

主 actor 上的编排层，连接 AppModel、模型管理、分句、生成、对齐、队列和播放。对界面提供：

- `startFromReadingPosition()`
- `startFromSelection(_ globalRange: NSRange)`
- `play()` / `pause()` / `stop()`
- `setRate(_ rate: Double)`
- 当前播放状态、当前句范围、下载状态和队列数量。

它负责在当前句变化时调用 `AppModel.updatePosition`，但不修改 `ReaderSession` 的权威语义。

## 用户交互

### 工具栏

在现有单一顶部工具栏增加听书按钮，沿用 30 × 30 pt 点击热区和浅灰 hover：

- 未播放：`headphones`，帮助文本“开始听书”。
- 准备或缓冲：显示小型进度指示，不允许重复启动。
- 播放：`pause.fill`，帮助文本“暂停听书”。
- 暂停：`play.fill`，帮助文本“继续听书”。

点击按钮：

1. 没有书时不显示或禁用。
2. 模型缺失时弹出按需下载确认，不直接联网下载。
3. 模型已就绪时从当前阅读位置所在完整句起播。
4. 播放中点击则暂停，暂停后点击则从当前句剩余位置继续。

倍速入口显示当前值，例如 `1.0×`。点击后弹出轻量 popover，包含 `0.5x...1.5x`、步长 `0.1x` 的滑杆和当前数值。倍速写入 `ReaderPreferences`，暂停、重启 App 和换书后保留。

### 选区浮层

连续和分页阅读都允许选择正文。选区非空且选择稳定后，在选区首个可见矩形附近显示轻量 AppKit popover，唯一动作是“从此处开始听”。

- 不覆盖系统文本选择能力。
- 点击后保存选区第一个全局 UTF-16 offset。
- 清除普通选区，切换为听书高亮。
- 若模型缺失，先弹下载确认；下载成功后仍从保存的选区起点开始。
- 若用户改变选区、滚动到选区不可见、切换模式或窗口隐藏，关闭浮层。

连续阅读通过 `VirtualTextWindow` 将局部选区映射为全局 UTF-16 范围；分页阅读通过当前 `PageRange.location` 加局部选区得到全局范围。

### 当前句高亮

高亮使用文本存储的背景属性，不使用覆盖正文的 SwiftUI 手势层。

- 连续模式：把全局范围映射进当前 `VirtualTextWindow`，只更新旧范围和新范围的属性；句子不可见时使用原生滚动使其可见。
- 分页模式：将全局范围映射到当前 `PageRange`。句子不在当前页时，以该句起点重新分页，再应用局部高亮。
- 高亮颜色从当前主题派生，确保明亮、柔和和深色主题均可读；不改变正文前景色。
- 暂停时保留当前句高亮；停止、换书或播放失败后移除。
- 模式切换时不改变全局句子范围，新文本视图按同一范围恢复高亮。

自动翻页或滚动只在当前句不再可见时发生，避免每句都重新定位导致画面跳动。

### 窗口与生命周期

- 自动隐藏窗口或进入悬浮阅读不会停止音频；否则现有隐身模式会频繁打断听书。
- 主动换书、删除当前书、删除模型或退出 App 会停止播放并取消生成。
- 关闭设置、打开书库和窗口置顶变化不影响播放。
- App 进入后台仍可播放；系统睡眠、音频设备变化和中断交由 AVAudioEngine 状态处理，恢复失败时进入暂停并提示。

## 数据与隐私

- 小说文本只进入本地模型，不上传、不记录到下载请求或日志。
- 网络仅用于获取固定模型清单和权重文件。
- 不保存整本书的合成音频；有界 PCM 队列在停止或换书后释放。
- 日志只记录模型状态、耗时、队列数量和错误类型，不记录小说原文或用户选区。
- `ReaderPreferences` 仅新增听书倍速，默认 `1.0`，解码旧配置时保持兼容。

## 许可证

- `mlx-audio-swift` 使用 MIT License。
- 两个固定模型 revision 的模型卡均标记为 Apache-2.0。
- 设置页的模型管理区域展示模型名称、来源链接、revision 和许可证。
- App 内保留依赖所要求的许可证文本；模型不随 App 分发，但下载确认和模型管理中仍显示来源与许可证。

## 错误处理

- 无网络：保留下载入口并提示“连接网络后重试”，普通阅读不受影响。
- 空间不足：下载前给出所需空间，不产生正式模型目录。
- 下载取消：保留可续传 `.partial` 文件，用户可在设置中清除。
- 校验失败：删除对应损坏分片后重试，不加载不完整模型。
- 模型加载失败：释放 MLX 资源，停止听书并保留阅读位置。
- 单块合成失败：最多重试一次；仍失败则暂停并显示简短错误。
- 单块对齐失败：该块回退逐句生成，后续块继续使用正常连续生成与对齐。
- 队列耗尽：进入缓冲状态，补充后自动恢复；不跳过正文。
- 快速连续跳转：generation ID 保证旧结果不能进入新队列。

## 性能与资源约束

- App 启动和普通阅读路径不得初始化 MLX、扫描模型或发起下载。
- 模型发现只在首次听书或设置页模型管理中触发。
- MLX 生成和对齐在串行专用执行器上运行，避免同时争抢统一内存。
- 先生成首句降低起播等待；后续使用 10/20/30 句水位保持可消费缓冲。
- 在 M3 Pro 18 GB 上验收时记录模型加载时间、首句起播时间、持续生成实时系数和峰值内存。
- 目标是暖机后无可感知段落空隙；若 1.7B 无法持续追上 1.0x 消费速度，则减少语义块长度，但不突破 30 句队列上限，也不静默更换模型。

## 测试策略

### Core 单元测试

- 中文引号、连续标点、省略号、换行和 emoji 的 UTF-16 分句。
- 当前阅读位置退回完整句首。
- 选区中点严格作为首条起点。
- 句子范围连续、无重叠、无丢字。
- 旧 `ReaderPreferences` 解码为 `speechRate == 1.0`，新倍速往返保存并限制在 `0.5...1.5`。

### App 单元测试

- 模型扫描优先级、完整清单验证、缺失容量计算和 partial 状态。
- 下载取消、恢复、校验失败和原子安装。
- 队列低水位 10、目标 20、上限 30。
- 暂停不越过目标水位，跳转清空队列，旧 generation ID 结果被丢弃。
- 播放速度改变后，源采样帧与句子高亮仍同步。
- 对齐词条合并为正确的全局 UTF-16 句子范围。
- 对齐失败只回退当前块。
- 连续模式局部/全局选区及高亮映射。
- 分页模式 `PageRange` 与局部选区及高亮映射。
- 自动窗口隐藏不停止播放，换书和退出会停止。

### 本地集成测试

真实模型测试不进入普通 CI，使用显式本地测试命令：

- 加载 1.7B 8-bit Serena 并生成固定中文夹具。
- 加载 4-bit ForcedAligner 并验证固定夹具得到有序时间范围。
- 在 `0.5x / 1.0x / 1.5x` 播放时核对句子切换。
- 验证本地已有 TTS 时只下载对齐模型。

### 人工验收

- 当前阅读位置起播、暂停、句中恢复和停止。
- 选中文字后“从此处开始听”，包括句中选择。
- 分页与连续模式整句高亮、自动翻页和自动滚动。
- 播放中切换阅读模式，高亮和位置不丢失。
- 10/20/30 句队列在长章节中稳定补充且不无限预生成。
- 首次下载、取消、断点续传、无网和空间不足。
- 模型删除后普通阅读正常。
- 顶部显示/隐藏、拖动、四边和四角 Resize 不受影响。
- 正文滚动、选择、复制和翻页不被浮层或高亮抢占。
- 空书库和已有书籍两种状态。

## 实施边界与顺序

实施按以下依赖顺序推进：

1. 原生 MLX 依赖与真实模型兼容性试验，锁定上游 commit。
2. Core 分句、倍速配置和队列状态机。
3. 模型发现、下载、校验和删除。
4. TTS、对齐、播放和 10/20/30 缓冲流水线。
5. 连续与分页文本视图的选区映射和句子高亮。
6. 工具栏、倍速 popover、下载界面和“从此处开始听”浮层。
7. 自动化测试、真实模型本地测试、窗口交互和打包签名验证。

功能实现需要独立 PR 进入 `main`，不得直接推送 `main`。模型权重不进入 Git 仓库、App 包或 Release 产物。
